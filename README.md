# Sundew · The Living Grove

Public experimental playtest. This repository contains only the compiled Three.js woodland and original Blender fox asset, not either classroom game.

Use the on-screen arrows to walk on a phone. Drag to orbit; pinch to zoom. On desktop use WASD, Shift to run, mouse drag and scroll.

Original character, textures and world assets authored for this experiment. Three.js is MIT licensed; see THREE-LICENSE.txt. No accounts, student data or analytics are implemented in the game.

Physical phone and student Chromebook testing is still pending.
