# Sundew · The Living Grove

Public graphics demonstration updated November 17, 2026. Includes the original Blender fox, reactive creek, mossy rocks and plants, rolling terrain and animated Blender woodland. This repository contains compiled playable files, not either classroom game or the private development sources.

Play: https://mendez84.github.io/sundew-living-grove-preview/

Desktop: WASD/arrow keys to walk, Shift to run, drag to orbit, scroll to zoom. Click nearby water to toss a pebble; Space sends a gust. Use Golden hour/Moonlit, Fine/Pixel view, and Return home to explore.

Original character, textures and world assets authored for this experiment. Three.js is MIT licensed; see THREE-LICENSE.txt. No accounts, student data or analytics are implemented in the game.

This is a graphics prototype. Actual student Chromebook and physical phone performance have not been verified. Older hashed bundles are retained so cached pages can still load during updates.
